Real Keycloak 26.2.5 (realm import with fixed user ids), real PostgreSQL 16.4 (RLS), tests in
`tests/security/test_api_scenarios.py`, `test_token_attacks.py`, `test_spoofing.py`,
`tests/integration/test_data_layer.py`, `tests/unit/test_authn.py`.

|---|---|

| T02 Alice reads payroll | 403; 0 side effects; audit reason `SUBJECT_NOT_GRANTED` |
